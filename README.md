# ap-storefront

Static mirror of [Anabolic Pharmacy AU](https://anabolicpharmacyau.com) for local/Cursor preview.

Serve with:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open http://127.0.0.1:8765/

Cart, checkout, account, and search are not functional (no WordPress/WooCommerce backend).
